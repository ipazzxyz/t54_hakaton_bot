# Reminder Bot для MAX

Проект разработан для хакатона от VK Education и MAX — интеллектуальный бот-помощник для управления напоминаниями с использованием AI для обработки естественного языка.

## 🚀 Возможности

- **Умное создание напоминаний** через естественный язык
- **Просмотр списка** всех ваших напоминаний
- **Редактирование и удаление** существующих напоминаний
- **Автоматическая отправка** напоминаний в указанное время
- **AI-обработка запросов** через OpenRouter

## ⚙️ Установка и настройка

### 1. Клонирование и зависимости
```bash
git clone <repository-url>
cd <project-directory>
pip install -r requirements.txt
```

### 2. Настройка окружения
Создайте файл `.env` в корне проекта:

- `MAXBOT_TOKEN` - получается при создании бота (разные способы получения)
- `OPENROUTER_API_KEY` - регистрация на [openrouter.ai](https://openrouter.ai)

### 3. Запуск через Docker

1. **Сборка контейнера:**
   ```bash
   docker build -t t54_hakaton_bot .
   ```

2. **Запуск контейнера:**
   ```bash
   docker run t54_hakaton_bot
   ```

**Или одной командой:**
```bash
docker build -t t54_hakaton_bot . && docker run t54_hakaton_bot
```

Бот автоматически:
- Создаст базу данных с таблицей напоминаний
- Запустит фоновую задачу проверки напоминаний
- Начнет принимать сообщения в MAX

## 💬 Использование

### Примеры команд:
- **Добавление**: "Напомни завтра в 9:00 позвонить маме"
- **Просмотр**: "Покажи все напоминания", "Что у меня сегодня?"
- **Редактирование**: "Перенеси встречу с инвестором на 15:00"
- **Удаление**: "У меня отменилась запись к врачу"

### Формат напоминаний:
```
ID   | Время            | Текст
---- | ---------------- | --------------------
 1   | 2025-11-14 09:00 | Позвонить маме
 2   | 2025-11-15 15:00 | Встреча с коллегами
```

## 🏗 Архитектура

### Основные компоненты:
- **AI Processing**: Обработка естественного языка через OpenRouter
- **Database Layer**: Асинхронные операции с SQLite
- **Scheduler**: Фоновая проверка и отправка напоминаний
- **MAX Handler**: Обработка входящих сообщений и команд

### Ключевые функции:
- `ai_request()` — обработка запросов через AI
- `check_due_reminders_loop()` — фоновая отправка напоминаний
- `db_fetch_user_reminders()` — получение напоминаний пользователя

## 🔧 Разработка

```

├── requirements.txt     # Зависимости
├── .env                # Переменные окружения

```

## ⚠️ Возможные проблемы

1. **Отсутствует OPENROUTER_API_KEY**
   - Бот будет работать, но AI-функции отключены

2. **Ошибки базы данных**
   - Проверьте права доступа к файлу БД
   - Убедитесь, что SQLite поддерживается
