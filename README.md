# 🤖 Бот-напоминатель с AI ассистентом

Умный бот для управления напоминаниями, который понимает естественную речь на русском языке. Просто говорите, что нужно сделать — бот поймёт и выполнит.

## ✨ Возможности

- **Создание напоминаний** через естественную речь
- **Просмотр всех напоминаний** в удобном формате  
- **Редактирование и удаление** существующих напоминаний
- **Умное распознавание** времени и контекста через AI
- **Персональные напоминания** для каждого пользователя

## 🛠 Технологии

- **Python 3.7+** - основной язык программирования
- **MaxBot API** - платформа для мессенджер-ботов
- **OpenRouter AI** - обработка естественного языка
- **SQLite** - локальное хранение данных
- **Docker** - контейнеризация приложения

## ⚡ Быстрый старт

### Настройка окружения

Создайте файл `.env` в корне проекта:

```env
OPENROUTER_API_KEY="ваш_ключ_openrouter"
MAXBOT_TOKEN="ваш_токен_бота_max"
```

**Где взять токены:**
- `MAXBOT_TOKEN` - получается при создании бота (разные способы получения)
- `OPENROUTER_API_KEY` - регистрация на [openrouter.ai](https://openrouter.ai)

### Запуск через Docker

1. **Сборка контейнера:**
   ```bash
   docker build -t t54_hakaton_bot .
   ```

2. **Запуск контейнера:**
   ```bash
   docker run t54_hakaton_bot
   ```

**Или одной командой:**
```bash
docker build -t t54_hakaton_bot . && docker run t54_hakaton_bot
```

### Локальная установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd <project-directory>

# Создание виртуального окружения
python -m venv venv
source venv/bin/activate  # Linux/MacOS
# venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

## 🐛 Решение проблем

### Частые вопросы:

**Бот не запускается: "MAXBOT_TOKEN is not set"**
- Проверьте наличие файла `.env` в корне проекта
- Убедитесь, что токены указаны без синтаксических ошибок

**AI не обрабатывает команды**
- Проверьте корректность `OPENROUTER_API_KEY`
- Убедитесь, что на аккаунте OpenRouter есть доступные запросы

**Напоминания не сохраняются**
- Проверьте права доступа к файлу базы данных
- Убедитесь, что директория доступна для записи
